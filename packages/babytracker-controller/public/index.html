RESOURCE & QUOTA LIMITS

Bound each run

Quota reports the shared account allowance. These dispatch/time budgets apply only to BabyTracker. Provider delays and in-flight work prevent an exact billing cutoff. Missing or stale quota blocks new work.

Current scope: controller, queue, project isolation and bounded dispatch are implemented. Explicit Codex and AGY worker provisioning is implemented. Automatic worker scaling, automatic AGY quota cutoff, disk I/O, acceptance ingestion and per-turn analytics remain planned. Saved preferences are not live provider identities; verified model handoffs are shown separately.

Change agent model

A Codex Chat model change is saved for the NEXT turn while any active turn finishes on its current model. Provider handoffs are queued until the agent is idle, then use the native AO session/worktree. No active turn is cancelled. AGY-to-AGY model swaps cannot currently be verified in place.

Add a project agent

Creates one isolated BabyTracker session with the selected live provider/model; does not send a task or start the fleet automatically.
